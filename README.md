# 1인 창업 유형소

창업을 앞두었거나 혼자 일하는 사람을 위한 유형 테스트 모음 사이트입니다.
설치할 것 없이 HTML/CSS/JavaScript만으로 동작하는 정적 사이트예요.

## 열어 보기
`index.html`을 브라우저(크롬, 엣지)로 열면 됩니다. (더블클릭)

## 폴더 구조
```
index.html        허브(테스트 목록)
test.html         테스트 화면 (시작 → 질문 → 결과). 주소의 ?id=테스트id 로 테스트를 고름
css/style.css     전체 스타일
js/data.js        사이트 이름, 카테고리 순서, 공용 도우미
js/hub.js         허브 화면 로직
js/test.js        테스트 진행·점수 계산·결과 화면 로직
js/tests/*.js     테스트 한 개당 파일 하나 (문구는 여기서만 수정)
img/              테스트 사진 (img/<테스트 id>.jpg)
```

## 문구 고치기
`js/tests/` 안의 해당 테스트 파일을 열어 글만 고치면 됩니다.
- 제목·부제·소개 문구: 파일 위쪽 `title`, `subtitle`, `hook`
- 질문과 선택지: `questions` (질문, A, B 순서)
- 결과 설명: 파일 아래쪽 `results`

문체 규칙: 질문은 “~은?/~때”, 선택지는 스스로에게 하는 말이라 “~다.”로 끝냅니다. (따옴표 안 속말은 그대로)

## 사진 넣기
`img/` 폴더에 **테스트 id와 같은 이름의 JPG**를 넣으면 허브 카드와 시작 화면에 자동으로 적용됩니다.

| 파일 이름 | 테스트 |
|---|---|
| `start-block.jpg` | 시작을 자꾸 미루는 진짜 이유 |
| `quit-timing.jpg` | 퇴사 타이밍 |
| `time-or-value.jpg` | 내 수입 구조 |
| `low-rate.jpg` | 단가 심리 |
| `founder-type.jpg` | 나의 일하는 방식 |
| `fail-style.jpg` | 번아웃 패턴 |

- 규격: 정사각형 1:1, 1200×1200px, JPG, 300KB 이하 권장
- 허브 카드에서 보이는 위치는 테스트 파일의 `cardPos`로 조정 (예: `"center 90%"`)
- 허브 카드 전용 가로 사진이 필요하면 `img/<id>-card.jpg`를 넣고, 해당 테스트 파일에 `cardImage: true`를 추가 (없으면 정사각형 사진을 씀)

## 새 테스트 추가
1. `js/tests/` 에 기존 파일 하나를 복사해서 `id`, 제목, 질문, 결과를 바꿉니다.
2. `index.html` 과 `test.html` 의 `<script src="js/tests/...">` 목록에 한 줄씩 추가합니다.
3. `img/<id>.jpg` 사진을 넣습니다.

## GitHub Pages로 공개하기
1. GitHub에서 새 저장소를 만들고 이 폴더의 파일을 올립니다.
2. 저장소의 **Settings → Pages** 에서 Source를 `Deploy from a branch`, Branch를 `main` / `(root)` 로 선택하고 저장합니다.
3. 잠시 뒤 안내되는 주소(`https://<아이디>.github.io/<저장소 이름>/`)로 접속합니다.

모든 경로가 상대 경로라서 저장소 이름이 주소에 들어가도 그대로 동작합니다.

## 참고
- 결과 화면의 퇴사 타이밍 테스트는 참고용이며, 재정 판단을 대신하지 않습니다.
- 이미지는 사이트에 사용해도 되는 것(직접 제작, 이용 약관상 허용되는 생성 도구 등)만 사용하세요.
